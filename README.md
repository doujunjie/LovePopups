#### 介绍

爱心弹窗源码，用于制造惊喜。程序会在屏幕上随机生成多个彩色暖心弹窗，最终汇聚成一个心形图案，是制造浪漫、表达心意的小工具。

**特点：**

- 运行、改代码重新编译都**不需要安装 JDK / JRE**：内置运行时（`runtime` 目录）负责运行，内置独立编译器 ECJ（`tools\ecj.jar`）负责编译，全部双击即用
- 纯 Java Swing 实现，运行时无需第三方依赖
- 动画采用 `easeOutCubic` 缓动函数，所有弹窗先快后慢、平滑汇聚成心形
- 13 种柔和配色 + 15 条暖心文案，每次运行随机组合
- 修复版：缩放比例、动画同步、中文乱码均已处理

#### 软件架构

- 语言：Java（源码 JDK 8 语法兼容；内置运行时为自带 JRE 21）
- GUI：Java Swing（`JFrame` + `JWindow`）
- 编译：无需 JDK，由自带 JRE 加载 Eclipse 独立编译器（ECJ 3.46，`tools\ecj.jar`）完成编译
- 数学：心形参数方程 + `easeOutCubic` 缓动 + 线性插值（lerp）
- 核心流程：
  1. 弹出问候窗口，询问"你今天快乐吗！"
  2. 点击"快乐 😊" → 隐藏主窗口，每隔 500ms 生成一个随机弹窗（共 50 个）
  3. 全部生成完毕后，以全局进度驱动所有弹窗从随机位置汇聚到心形目标位置
  4. 心形定格 5 秒后，自动关闭所有窗口并退出 JVM
- 目录结构：
  ```
  弹窗爱心/
  ├── runtime/              # 内置 JRE 21 运行时（运行 + 编译都靠它，无需安装 JDK）
  ├── tools/
  │   └── ecj.jar           # Eclipse 独立编译器，供"重新编译.bat"使用
  ├── LovePopups.java       # 源代码
  ├── LovePopups.class      # 编译后的字节码（含内部类 $1、$2）
  ├── 启动.bat              # 一键运行脚本（推荐）
  └── 重新编译.bat          # 修改源码后一键重新编译（同样无需 JDK）
  ```

#### 安装教程

无需安装 JDK，也无需任何配置。

1. 下载 / 克隆本仓库到本地
2. 确保 `runtime` 文件夹与 `启动.bat` 在同一目录下
3. 双击 `启动.bat` 即可运行

> 若直接运行报错，请确认 `runtime\bin\java.exe` 存在，且 `LovePopups.class` 已编译生成。

#### 使用说明

1. 双击 `启动.bat` 启动程序
2. 在弹出的问候窗口中点击 **"快乐 😊"** 按钮
3. 屏幕上会陆续出现 50 个彩色暖心弹窗，最终汇聚成一个 ❤ 心形
4. 心形展示约 5 秒后自动关闭
5. 若想调整效果，编辑 `LovePopups.java` 顶部"可自定义配置区"的常量后，双击 `重新编译.bat` 重新编译（使用自带 runtime + ECJ，**无需安装 JDK**），再运行 `启动.bat`

**可自定义参数（在** **`LovePopups.java`** **中修改）：**

| 常量                      | 默认值    | 说明             |
| ----------------------- | ------ | -------------- |
| `POPUP_COUNT`           | 50     | 弹窗数量           |
| `SPAWN_INTERVAL_MS`     | 500    | 弹窗生成间隔（毫秒）     |
| `HEART_SCALE`           | 15     | 心形缩放比例（越大心形越大） |
| `ANIMATION_DURATION_MS` | 2000   | 心形动画总时长（毫秒）    |
| `ANIMATION_FPS`         | 60     | 动画帧率           |
| `POPUP_SIZE`            | 200×80 | 单个弹窗尺寸         |
| `COLORS`                | 13 种   | 弹窗背景色数组        |
| `MESSAGES`              | 15 条   | 暖心文案数组         |

> 提示：`重新编译.bat` 不依赖系统安装的 JDK，它使用 `runtime\bin\java.exe` 加载 `tools\ecj.jar`（Eclipse ECJ 编译器）完成编译。请勿删除或移动 `runtime`、`tools` 文件夹，且需与 `重新编译.bat` 保持在同一目录。
